## 벌처 호스팅은 어떤 서비스인가

Vultr는 클라우드 컴퓨팅과 가상 전용 서버를 주력으로 하는 호스팅 업체다. 한국어로는 '벌쳐'로 많이 읽는다. 가격 대비 성능으로 자주 언급되는 곳이고, 관리 화면이 심플하고 직관적이라 서버를 깊게 모르는 사람도 접근하기 쉬운 편이다. Linode나 DigitalOcean 같은 오래된 업체보다 역사는 짧지만, 가성비와 프로모션으로 자리를 잡았다.

안정성 쪽도 살펴볼 만하다. Vultr는 100.0% 업타임을 SLA로 내걸고 있고, 서버가 5분 이상 다운되면 그에 상응하는 크레딧을 지급한다. 실제로 도쿄 서버가 1시간 이상 다운됐던 사례에서는 서버당 600달러 정도의 크레딧이 돌아갔다.

기술적인 특징 중 실용적인 것들만 골라보면 이렇다.

- VPS마다 IPv4가 기본 1개 제공되고, IPv6는 무료로 받을 수 있다.
- 모든 VPS에 고성능 SSD가 쓰이며, 서버 생성은 보통 30초에서 1분 걸린다.
- 관리 콘솔이 웹 기반이라 별도 프로그램 없이 서버 원격 화면을 볼 수 있다. noVNC로 구현된 기능인데, 방화벽 설정을 잘못 건드려 SSH 접속이 끊겼을 때 이 버튼으로 복구 작업을 이어갈 수 있다. 모바일은 콘솔 조작이 조금 불편하다.
- CPU·디스크·네트워크 사용량을 패널에서 바로 확인할 수 있고, API도 지원한다.
- 한번 할당된 IP는 전원을 꺼도 바뀌지 않는다. 다만 전원을 꺼도 자원을 계속 점유한 것으로 간주해 요금은 그대로 나간다. 이 부분은 뒤에서 다시 짚는다.

무료 플랜은 2023년 3월에 발표됐다. 얼리 액세스 방식이라 신청자 중에서 가중치 점수를 합산해 무작위로 선정되고, 데이터 센터가 미국 마이애미·시애틀, 독일 프랑크푸르트로 제한된다. Ubuntu나 Arch Linux, Windows Server OS를 선택하면 무료 플랜 선택지가 사라지는 등 제약이 여럿 있다. 구성만 봐도 실서비스용이라기보다 테스트 서버 용도에 맞다.

## 서울 리전, 고르기 전에 확인할 것

서울 리전이 있다고 해서 한국 사용자에게 무조건 가장 빠른 것은 아니다. 2024년 8월 기준으로 서울 리전 VPS에 접속하면 국내 서버로 직결되지 않고, 해외 리전 트랜짓을 거친 뒤 국내로 도달한다. 주로 일본이나 동남아 쪽을 경유하는데, 실제로 서울 VPS에서 핑을 찍어보면 일본 VPS와 차이가 없다. 껍데기만 한국 서버인 셈이다.

이게 나쁘다는 얘기는 아니다. 요금은 지역과 무관하게 같으니, 네트워크 성능이 도쿄와 사실상 같다면 선택 기준은 오히려 단순해진다. 서울 리전의 초과 트래픽 단가(1GB당 0.05달러)와 부가 기능의 리전 제약만 함께 보면 된다. GPU 인스턴스는 A100·A40·A16 세 종류 모두 서울을 지원하지 않으니, GPU 용도라면 처음부터 다른 리전을 봐야 한다.

## 워드프레스·웹서버 개설 절차

개설 자체는 어렵지 않다. 로그인 후 다음 순서로 진행하면 된다.

1. 좌측 메뉴에서 Products를 클릭한다.
2. Cloud Compute를 선택한다. 가벼운 웹서버 용도라면 여기서 시작하는 게 맞다.
3. 리전을 고른다. 앞서 본 서울 리전의 네트워크 실상을 감안해 일본이나 미국을 고르는 경우가 많다.
4. 운영체제를 고른다. 워드프레스나 일반 웹서버라면 Ubuntu 22.04 LTS 같은 배포판이 무난하다.
5. Auto Backups 옵션이 나오는데, 필요 없으면 해제하고 진행해도 된다. 나중에 다시 켤 수 있다.
6. 카드를 등록하면 결제가 진행되고 서버 생성이 시작된다. 보통 30초에서 1분이면 끝난다.

생성이 끝나면 서버 화면에서 IP를 확인하고 웹 기반 콘솔로 바로 작업에 들어갈 수 있다. 👉 [Cloud Compute 요금제 보고 서버 개설하기](https://bit.ly/VulTR)

## 과금에서 실수하기 쉬운 부분

벌처 호스팅에서 요금이 예상보다 나오는 지점은 대부분 세 가지로 모인다.

첫째, 전원을 꺼도 과금된다. 할당된 자원을 계속 점유한 것으로 간주하기 때문이다. 사용을 멈출 계획이라면 서버를 삭제(Destroy)해야 이후 추가 과금이 멈춘다.

둘째, 백업 관련 비용이다. 스냅샷은 유료화됐고 GB당 월 0.05달러가 청구된다. 저장에 서버당 5분 이상 걸릴 수 있고, 스냅샷을 찍은 서버보다 낮은 사양의 서버에는 복원이 불가능하다. ISO 업로드는 8기가까지, 2개까지 지원되니 자주 쓰는 설치 이미지는 올려두고 재사용할 수 있다.

셋째, 리전별 초과 트래픽 단가다. 기본 트래픽 한도는 지역이 같아도 초과 과금은 다르고, 서울과 호주는 1GB당 0.05달러다. 트래픽이 많은 서비스라면 내 리전의 초과 단가를 요금제 페이지에서 확인해두는 편이 좋다.

Windows는 조금 다른 함정이 있다. ISO 업로드로 직접 설치하면 라이선스 비용을 내지 않아도 되지만, Windows 설치 이미지에는 KVM 가상화에 쓰이는 VirtIO 드라이버가 기본 포함되어 있지 않아 별도 통합 작업이 필요하다.

## 해지 방법: 버튼 하나로 끝나지 않는다

벌처 호스팅 해지는 서버 삭제와 계정 탈퇴, 두 단계로 나뉜다. 그리고 계정을 즉시 탈퇴하는 메뉴가 없다. 해외 사이트에서 종종 보이는 방식인데, 별도로 티켓을 열어 신청해야 한다.

절차는 이렇다.

1. 먼저 서버를 삭제한다. 로그인 후 서버 화면에서 Server Destroy를 클릭하고, 삭제할 서버를 확인한 뒤 Destroy Server 버튼을 누른다. 바로 사라지지는 않고 잠시 후 삭제된다. 서버를 지워야 이후 추가 비용이 멈춘다.
2. Billing 메뉴에서 카드 정보를 지우려 하면 실패한다. 이번 달 청구할 서버비가 있으면 결제 수단을 최소 하나는 남겨두라는 안내가 뜬다. 정상적인 동작이다.
3. 좌측 Support 메뉴에서 Open Ticket을 클릭한다. 카테고리에서 Account Cancellation을 선택하고, 서버는 이미 삭제했다면 None으로 둔다. 지불 수단 삭제와 계정 취소를 요청하는 제목과 내용을 작성해 제출한다. 구글 번역기로 작성해도 무방하지만 정중하게 쓰는 편이 좋다.

티켓을 열면 즉시 답변이 오지 않는다. 상태가 Open으로 있다가 답변이 달리면 Feedback으로 바뀌고, 등록한 이메일로도 안내가 온다. 실제 사례에서는 하루 뒤에 "이번 달 지불 잔액 때문에 계정을 바로 해지할 수 없으며, 정산이 되는 대로 해지하겠다"는 답변이 왔다. 서버를 삭제하고 티켓만 열어두면 정산 후 알아서 처리되니, 며칠의 시간이 더 든다는 것까지 염두에 두면 된다.

## 자주 묻는 질문

### 벌처 호스팅 최저 요금은 얼마인가?

미국 애틀랜타·뉴욕의 IPv6 전용 플랜이 월 2.5달러다. IPv4가 필요하면 뉴욕의 3.5달러 플랜(1 CPU, 512MB 램) 또는 월 5달러부터 시작한다.

### 서버를 꺼두면 요금이 나오지 않나?

나온다. 전원을 꺼도 자원을 계속 점유한 것으로 간주해 요금이 그대로 청구된다. 사용을 멈출 거면 서버를 삭제하는 것이 확실하다.

### 무료로 쓸 수 있는 방법은 없나?

무료 플랜이 있지만 얼리 액세스 방식이다. 신청자 중에서 무작위로 선정되며, 리전이 마이애미·시애틀·프랑크푸르트로 제한되고 1 vCPU·512MB RAM·10GB SSD 구성이라 테스트 용도에 적합한 수준이다.

### 서버가 다운되면 보상이 있나?

100.0% 업타임을 SLA로 내걸고 있어 5분 이상 다운되면 상응하는 크레딧을 지급한다. 도쿄 서버가 1시간 이상 다운됐던 때는 서버당 600달러 정도가 지급됐다.

### 한국에서 쓰면 느리지 않은가?

서울 리전도 트래픽이 해외(주로 일본·동남아)를 경유해 도달한다. 핑은 도쿄 VPS와 차이가 없어서, 성능이 비슷하다면 리전 선택은 초과 트래픽 단가 같은 다른 조건으로 결정해도 된다.

## 결국 어떻게 고를까

요금제를 고를 때 기준은 단순하게 잡을 수 있다.

- 가벼운 블로그, 테스트 서버: Cloud Compute의 Regular Performance(월 5달러). 저장공간이 SSD가 아니라는 점만 감안하면 된다.
